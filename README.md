# Предсказание движения цен на акции на основе текстовых данных

Годовой проект группы 132.

Цель проекта: понять, помогают ли новости и обсуждения инвесторов предсказывать рост или падение цен на акции. Тексты сопоставляются с историческими котировками по времени публикации и используются для обучения моделей. Результатом станет сравнение разных способов обработки текста и моделей между собой, а также с прогнозом только по котировкам.

## Планируемые источники данных

- Исторические котировки российских акций: [Московская биржа (ISS)](https://www.moex.com/ru/documents/6523).
- Новости: [«РБК Инвестиции»](https://www.rbc.ru/quote/category/News/).
- Обсуждения инвесторов: [«Пульс» Т-Банка](https://www.tbank.ru/invest/help/services/pulse/about/about/) и [форум Smart-Lab](https://smart-lab.ru/forums/).

## План работы

- Собрать исторические котировки акций и тексты из новостей РБК и обсуждений в «Пульсе» Т-Банка.
- Подготовить тексты для обучения и сравнить разные способы предобработки.
- Получить эмбеддинги текстов разными методами и сравнить их.
- Разработка ML-классификаторов
- Разработка DL-классификаторов
- Обертка сервисов: создание телеграмм-бота, разворачивание сервиса на Kubernetes
